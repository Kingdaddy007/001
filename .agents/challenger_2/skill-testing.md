Core Methodology:
- Test behaviors, not implementation details.
- Economical confidence mindset: maximize useful confidence per unit of maintenance cost.
- Apply testing lenses: risk importance, behavior vs implementation detail, boundary realism, etc.
- Run tests on the smallest meaningful test level (types/static analysis -> unit -> integration -> E2E).
