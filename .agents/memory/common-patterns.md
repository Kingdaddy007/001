# Common Patterns

## The Cinematic Window Transition
Used for transitioning from abstract brand authority (black screen/text) to spatial proof (video).
- **Pattern:** `[Pinned Black Container] -> [Z-Axis Text Scale/Fade] -> [Video Reveal underlying]`

## The Layered Diorama Parallax
- **Pattern:** Using Lenis to smoothly parallax a full-bleed video *slower* than the scrolling typography, giving the illusion of looking through a window into a real 3D room.
