# ANTI-TEMPLATE PREFLIGHT: THRESHOLD by Adebayo

## The Generic Layout (The Weak AI Default)

If a generic system built this site, it would output:
1. **A Floating Navigation Bar:** Logo on the left (e.g. "Threshold"), standard links in the middle (Home, Projects, About, Contact), and a generic button on the right ("Book a Consultation").
2. **Standard Hero Section:** A centered H1 reading "Bespoke Brutalist Architecture" or "Luxury Spatial Design in Lagos & Milan". Below it, a two-line paragraph of filler text, followed by a primary button ("View Work") and a secondary button ("Our Services").
3. **The Background Image:** A stock photo of a concrete living room with a heavy black overlay to make the white text readable.
4. **The Scroll Transition:** Simple fade-ins (`opacity: 0` to `1`) using a standard CSS transition or an out-of-the-box library preset.

---

## Tidescape Failure Modes Present in Defaults

- **The Commodity Decorator Smudge:** Treating the studio like a vendor selling furniture styling rather than an architectural practitioner sculpting volume.
- **Visual Weightlessness:** Having massive concrete slabs fly in or fade with elastic/bouncy easing, which violates the physical laws of concrete (mass).
- **The Active Grid Trap:** Presenting finished spaces in a standard 3-column card grid, which reduces three-dimensional architectural scale to flat 2D stamps.
- **Submissive Copywriting:** Explaining *why* the designer is good or list hours/methods, which immediately signals a lower-tier performer posture.

---

## Banned Structures, Components, and Assets

### Banned Structures
- Centered grid alignments for hero copy.
- Floating headers that follow scroll with a glassmorphism/backdrop-filter effect.
- Two-button call-to-action clusters.
- Arrow-based carousel sliders.

### Banned Fonts
- Inter, Roboto, or Open Sans used as display headings (looks like SaaS, not luxury).
- Playfair Display or Montserrat used as massive display serif (too generic, overused by mid-market spas and templates).

### Banned Colors
- Standard template grays (e.g., `#333`, `#666`, `#eaeaea`).
- Pure flat white backgrounds for content zones.
- Generic primary blues/greens.

### Banned Animation Presets
- Elastic, bouncy, or jittery easing.
- Simple, instant opacity fades without spatial movement.
- Rotating or spinning elements.

### Banned Placeholders
- `Lorem Ipsum` or generic text like "We are a creative agency...".
- Default Unsplash interior images that show decorative cushions, colorful rugs, or generic mid-century chairs.

---

## The "Swap-Industry" Test

If we swap the copy on the generic template from "Brutalist Space" to "Organic Skincare Brand" or "Crypto Asset Management," and the layout, visual structure, and motion still make sense, then the template has **failed** the test. 

**THRESHOLD's showroom must only make sense for architecture and spatial volume.** The layout elements themselves must look like heavy monolithic blocks and shadows.
